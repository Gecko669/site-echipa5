# Personal Website cu UIkit 3.23.x

Acest proiect este un site web personal creat folosind UIkit 3.23.x. El prezintă portofoliul unui dezvoltator web și designer UI/UX, incluzând mai multe pagini și elemente interactive.

## Project Overview

Acest site web personal este alcătuit din trei pagini cu structuri diferite:

1. **Home Page** - Proiectul include o secțiune hero, o pagină „Despre mine”, servicii oferite, lucrări de portofoliu selectate și testimoniale.
2. **Portfolio Page** - Afișează proiectele cu funcționalitate de filtrare și o galerie tip lightbox.
3. **Contact Page** - Include un formular de contact cu validare și procesare PHP.

##Personalizări
Stilizarea implicită UIkit a fost personalizată prin modificarea următorilor parametri:

Schematizare de culori personalizată cu culori primare, secundare și accentuate

Tipografie personalizată folosind fonturi Google Fonts (Montserrat pentru titluri, Poppins pentru textul de corp)

Efecte hover și animații îmbunătățite pentru elementele interactive

Stilizare și validare personalizată pentru formulare

Ajustări de design responsive pentru diferite dimensiuni de ecran
