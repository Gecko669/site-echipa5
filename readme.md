# Personal Website with UIkit 3.23.x

This project is a personal presentation website built using UIkit 3.23.x framework. The website consists of 3 distinct pages with different layouts, each showcasing different capabilities of the UIkit framework while maintaining a consistent and professional design.

## Team Members

- John Smith (Team Coordinator) - Home page development, project setup, UIkit customization
- Sarah Johnson - Portfolio page development, image optimization, documentation
- Michael Brown - Contact page development, form validation, PHP integration
- Emily Davis - Responsive design implementation, testing, custom component styling

## Project Structure

```
/
├── index.html              # Homepage
├── portfolio.html          # Portfolio/Projects page
├── contact.html            # Contact page
├── display.php             # Page to display form data
├── mail.php                # PHP script for form processing
├── css/
│   └── uikit.min.css       # Customized UIkit CSS
├── js/
│   ├── uikit.min.js        # UIkit JS
│   └── uikit-icons.min.js  # UIkit icons
└── readme.md               # Project documentation
```

## Features

1. **Three Distinct Pages**
   - Home page with hero section, services, and skills
   - Portfolio page with project gallery and filtering
   - Contact page with form and information

2. **Responsive Design**
   - Sticky navbar for desktop
   - Off-canvas menu for mobile
   - Responsive layouts for all screen sizes

3. **Advanced UIkit Components**
   - All required UIkit components implemented
   - Custom styling of UIkit elements
   - Enhanced animations and transitions

4. **Contact Form**
   - Form validation
   - PHP integration for form processing
   - Display page for form submissions

5. **Custom Styling**
   - Modified UIkit CSS parameters
   - Google Fonts integration (Montserrat for headings, Roboto for body)
   - Enhanced color scheme and component styling

## Customization

The UIkit framework has been customized by modifying the following parameters in the uikit.css file:

1. **Typography**
   - Custom font families using Google Fonts
   - Enhanced heading styles
   - Improved text readability

2. **Color Scheme**
   - Modified primary color
   - Enhanced button and card colors
   - Custom alert and notification styling

3. **Component Styling**
   - Enhanced button appearance with subtle animations
   - Improved card design with hover effects
   - Custom navbar and off-canvas menu styling
   - Refined form elements for better usability

4. **Animation and Transitions**
   - Smooth transitions for interactive elements
   - Enhanced scrollspy animations
   - Improved hover effects

## Sources of Inspiration

The website design was inspired by modern portfolio websites with clean, professional aesthetics and strong visual hierarchy. No specific template was directly copied, but the design drew inspiration from various professional portfolio sites and UIkit's own documentation and examples.

## Setup Instructions

1. Clone this repository
2. Ensure you have a server environment that supports PHP (e.g., XAMPP, WAMP)
3. Place the project files in your web server directory
4. Access the website through your local server (e.g., http://localhost/personal-website)
